Propuesta Comercial

Presupuesto para sistema de catálogo web con gestión por WhatsApp

Fecha: 7 de abril de 2026
Moneda: USD
Validez: 15 días

Alcance

Desarrollo e implementación de un sistema de catálogo web multitenant para publicación de productos, administración simple mediante Google Sheets y consultas comerciales directas por WhatsApp, sin pasarela de pago.

Incluye

  • Landing/home personalizada con destacados, categorías y banners administrables.
  • Catálogo web responsive con filtros por categoría, condición, color, capacidad y rango de precio.
  • Ficha de producto con variantes, estado de unidad, descripción comercial y CTA a WhatsApp.
  • Carrito de consulta para agrupar varios productos y enviar una sola conversación estructurada por WhatsApp.
  • Backoffice simple con Google Sheets como base operativa de carga y edición.
  • Sincronización entre Google Sheets y Supabase para publicación de datos en la web.
  • Uploader interno de imágenes con login por magic link, optimización automática a WebP y generación de URL pública lista para pegar en Sheets.
  • Configuración inicial de Supabase, storage, permisos, variables de entorno y despliegue.
  • Estructura preparada para trabajar por cliente mediante client_id y separación de datos.

Modelo de trabajo

  • La tienda administra productos, categorías, configuración y contenido desde Google Sheets.
  • Las imágenes se suben desde un panel interno y luego se vinculan pegando la URL en Sheets.
  • Los visitantes no compran directamente en la web: consultan por WhatsApp de forma individual o con carrito múltiple.

Inversión

Desarrollo e implementación

USD 250

Pago único por armado, configuración, puesta en marcha y entrega inicial del sistema.

Mantenimiento mensual estimado

USD 20

Incluye hosting, base de datos, storage, soporte operativo básico y pequeños ajustes menores.

No incluye

  • Pasarela de pagos, checkout online o facturación electrónica.
  • Campañas publicitarias, carga masiva inicial de catálogo o producción de contenido fotográfico.
  • Desarrollos especiales fuera del alcance acordado.
Propuesta orientada a un sistema práctico, escalable y fácil de administrar para venta asistida por WhatsApp.
El objetivo es reducir fricción operativa, simplificar la carga de productos y mantener una presencia web profesional.
